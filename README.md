# SN NEWS — Website Source

Responsive frontend demo for এস এন নিউজ (SN NEWS), Sonagazi, Feni.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — filters, search, article detail modal, ticker and navigation
- `assets/` — supplied SN News logo, milestone banner and editor portrait crop

## Run locally
Open `index.html` in a modern browser. An internet connection is required for Google Fonts and remote Unsplash placeholder/editorial images.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.

## Important content note
The sample news cards are short, attributed summaries based on the external source links displayed on each card. They are not claimed to be original SN NEWS reporting or confirmed posts from the SN News Facebook page. Replace/update them with newsroom-verified reports and the channel's own approved photos before production.

## Backend note
This is a static frontend website. It does not yet include a CMS/admin login, database, live newsroom publishing workflow, or connected newsletter service.
